# Bloom frontend

Bloom is a mobile plant discovery and community app from the first cohort of the Holberton School AI Accelerator. The React Native and Expo frontend lives in `mobile/`.

All eight planned frontend screens are implemented. Discovery, Plant Details, and Seasons use local sample plant data. Alerts uses example notices, and the sighting, account, and community review flows run locally. Backend integration is a future step.
